# HALLOW NIGHT — original version (backup)

A playable copy of the game as it was before the remake: the original 35 levels
in 7 worlds, the old movement, no bosses. Its saved progress is kept separately
from the new game's.

Play it at https://coding-joule.github.io/Hallow-Night/original/
(its level editor is at `original/editor/`).

These are the built files, copied as they were. The source code for this
version is in the git history at commit `a06cb2a`
("Inside the Gears: make the purple platform climb much easier").
